# SigmaOS-linuxmint

> **SigmaOS Linux Mint Inspirations & Usability Subsystem** — Onboarding, Warpinator LAN transfer, Mint driver/locale integration, XApps, Bulky renamer, and Hypnotix IPTV.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.

## Quickstart

```bash
cargo build --release
cargo test
```
